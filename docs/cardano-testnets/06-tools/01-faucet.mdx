Since Cardano testnets are independent networks, separate from the Cardano
mainnet, they require their own tokens.

The faucet is a web-based service that provides test ada to users of the Cardano
testnets. While these tokens have no 'real world' value, they enable users to
experiment with Cardano testnet features, without having to spend real ada on
the mainnet.

### Request test ada

1. Under **Environment**, select **Preview Testnet** or **Preprod Testnet** to
   match the network you are using.
2. Under **Action**, select **Receive test ADA**.
3. Enter the testnet address where you want to receive funds.
4. If you have been issued with an API key, enter it to use your assigned
   rate limit. A valid API key does not require CAPTCHA. Otherwise, complete
   the CAPTCHA challenge.
5. Click **Request funds**.

The **Transaction submitted** message identifies the destination address and
shows the transaction hash. Wait for confirmation on the selected network,
then check the receiving address's balance. Submission does not mean the
transaction is already confirmed.

### Delegation

If you're an SPO, you can request faucet stake to be delegated to your pool
to test stake pool operations.

1. Under **Environment**, select the network where your pool is registered:
   **Preview Testnet** or **Preprod Testnet**.
2. Under **Action**, select **Receive pool delegation**.
3. Enter your pool ID in bech32 format (`pool1...`).
4. Enter an API key with delegation permission, if you have one, or complete
   the CAPTCHA challenge. API keys use their assigned rate limit.
5. Click **Request funds**.

The **Transaction submitted** message identifies the pool and shows the
transaction hash. Wait for confirmation on the selected network, then check
the delegation to your pool. Delegation assigns faucet stake to your pool;
it does not transfer the faucet's funds to your wallet.
